# ASLI — ربات ترکیبی فارکس و طلا (ICT + LIT + خط روند + CRT + ORB + اسکلپ طلا)

ASLI روی متاتریدر ۵ معامله می‌کند. شش سبک را جداگانه بک‌تست می‌گیرد، نقطه‌ی قوت هر کدام را (سشن، ساعت، جهت روز، هم‌جهتی) پیدا می‌کند، آن‌ها را در یک سبک ترکیبی ادغام می‌کند، از هر معامله یاد می‌گیرد، تقویم اقتصادی و اخبار روز را در نظر می‌گیرد، و قبل از باز شدن هر پوزیشن یک **ایجنت مخالف** باید با دلیل قانع شود.

## اجزای برنامه

| بخش | فایل | کار |
| --- | --- | --- |
| ۶ سبک | `asli/strategies/` | ICT Model 2022 (raid → MSS → FVG در کیل‌زون)، LIT (BOS → پولبک معتبر → گرفتن IDM → اوردربلاک اکستریم با FVG)، خط روند (خط TD دی‌مارک + sweep نقدینگی خط)، CRT (کندل‌های H4 ساعت ۱/۵/۹ نیویورک + سطح کلیدی)، ORB (رنج ۳۰ دقیقه‌ای لندن + فیلتر SMA200 و عرض رنج)، اسکلپ طلا (پولبک تند RSI(2) هم‌جهت با روند ساعتی؛ فقط طلا) |

| سبک ترکیبی | `asli/fusion.py` | همه‌ی کاندیداها با ویژگی‌های زمینه (جهت روز، روند، هم‌جهتی/مخالفت سبک‌ها، کیل‌زون، سطح کلیدی، پریمیوم/دیسکانت)؛ آموزش روی ۶۰٪ اول داده و تست روی ۴۰٪ دیده‌نشده (walk-forward) |
| یادگیرنده | `asli/learner.py` | رگرسیون لجستیک: احتمال برد و امید ریاضی هر کاندیدا؛ جدول لبه‌ی هر سبک در هر ساعت و هر سشن؛ بعد از هر معامله‌ی زنده خودش را به‌روز می‌کند |
| فاندامنتال | `asli/fundamental.py` | تقویم اقتصادی ForexFactory (بازه‌ی ممنوعه ±۳۰ دقیقه برای خبر قرمز، ±۱۰ برای نارنجی) + تیترهای خبری RSS با امتیاز hawkish/dovish و ریسک‌گریزی برای هر ارز |

| داشبورد و API | `asli/server.py` | صفحه‌ی وب روی پورت 8787 + API برای اپ |

## طلا

طلا (هر نمادی که با `XAU` شروع شود، مثل `XAUUSD_o`) را به `symbols` در `config.yaml` اضافه کنید. چون پیپ طلا ۰.۱ دلار است، طلا محدوده‌ی استاپ و هزینه‌ی جدای خودش را دارد (استاپ ۱۰ تا ۱۰۰ پیپ یعنی ۱ تا ۱۰ دلار، کمیسیون ۲ پیپ، اسلیپیج ۱ پیپ). برای تغییر آن‌ها برای یک نماد خاص از `symbol_overrides` در `config.yaml` استفاده کنید (نمونه در `config.example.yaml`).

## اسکلپ طلا (`asli/strategies/scalp.py`)

فقط روی نمادهای `XAU...` کار می‌کند. قانون‌ها:

- **روند:** قیمت بالای میانگین ۵۰ و ۲۰۰ ساعتی (SMA 600 و 2400 روی M5)، و روی M5 EMA50 بالای EMA200 و رو به بالا (برای فروش برعکس)
- **ماشه:** RSI(2) کندل بسته‌شده ≤ ۵ (برای فروش ≥ ۹۵)؛ یعنی یک افت تند ۲ تا ۳ کندلی داخل روند صعودی
- **زمان:** ۰۲:۰۰ تا ۱۲:۰۰ نیویورک (صبح لندن و نیویورک)
- **خروج:** تارگت ۰.۷۵ ATR، استاپ ۴ ATR، بستن خودکار بعد از ۴ ساعت؛ بیشتر معامله‌ها ۱۰ تا ۳۰ دقیقه طول می‌کشند

**چطور انتخاب شد:** چهار خانواده‌ی معروف اسکلپ (برگشت به میانگین با بولینگر/RSI، پولبک هم‌جهت روند، شکار نقدینگی رنج آسیا/لندن، خستگی چند کندل پشت‌سرهم) با حدود ۱۹۰۰ ترکیب تنظیمات روی داده‌ی M5 طلای همین بروکر (ژوئن ۲۰۲۵ تا نوامبر ۲۰۲۶) با اسپرد واقعی هر کندل، کمیسیون ۰.۰۵ دلار برای هر اونس و ۱ پیپ اسلیپیج تست شدند. انتخاب فقط روی ۶۰٪ اول داده انجام شد و ۴۰٪ آخر دیده‌نشده ماند. از بین تنظیماتی که روی هر دو بخش و با هزینه‌ی دو برابر هم سودده ماندند، این بیشترین وین ریت را داشت:

| | معامله | وین ریت | میانگین R | PF |
| --- | --- | --- | --- | --- |
| کل دوره | ۳۴۸ | ۸۷.۹٪ | +0.049 | 1.48 |
| بخش دیده‌نشده | ۱۲۱ | ۹۰.۱٪ | +0.080 | 2.03 |

**هشدار:** وین ریت بالا از این است که تارگت حدود ۵ برابر نزدیک‌تر از استاپ است؛ یک ضرر تقریباً سود ۵ برد را می‌برد. لبه واقعی است ولی نازک. خانواده‌های برگشت به میانگین و شکار نقدینگی، با وجود ادعاهای اینترنتی، بعد از هزینه‌ها روی این داده سودی نداشتند. تنظیمات در `strategies.scalp` در `config.yaml` قابل تغییر است (مثلاً `tp_atr: 0.5` وین ریت را به حدود ۹۳٪ می‌برد ولی لبه را نازک‌تر می‌کند).

## قفل‌های ایمنی

- `mode: demo` (پیش‌فرض): ربات **فقط روی حساب دمو** معامله می‌کند و اگر حساب واقعی وصل باشد خاموش می‌شود.
- برای حساب واقعی هر دو لازم است: `mode: real` **و** `allow_real: true`.
- ریسک هر معامله ۰.۵٪، حداکثر ضرر روزانه ۲٪، حداکثر ۲ پوزیشن، نصف شدن ریسک بعد از ۳ ضرر پیاپی.
- رمز متاتریدر و `config.yaml` هرگز در GitHub قرار نمی‌گیرند.

## نصب روی سرور ویندوز (یک بار)

۱. با Remote Desktop وارد سرور شوید. متاتریدر ۵ را نصب کنید و با حساب **دمو** وارد شوید.
   - Tools → Options → Expert Advisors → تیک «Allow algorithmic trading»
   - Tools → Options → Charts → Max bars in chart = Unlimited

۲. PowerShell را **Run as Administrator** باز کنید و بزنید:

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force
iwr https://raw.githubusercontent.com/sejek005-afk/asli/main/windows/install.ps1 -UseBasicParsing | iex
```

اگر ریپو خصوصی است، دستور بالا کار نمی‌کند: از صفحه‌ی ریپو **Code → Download ZIP** را بگیرید، در `C:\asli` باز کنید و `C:\asli\windows\install.ps1` را اجرا کنید.

نصاب، توکن اپ را در آخر چاپ می‌کند. آن را یادداشت کنید.

۳. تنظیمات:

```powershell
notepad C:\asli\config.yaml          # mt5.login، mt5.server، symbols (اسم دقیق از Market Watch)
setx ASLI_MT5_PASSWORD "رمز-حساب-دمو"   # بعدش یک PowerShell جدید باز کنید
```

۴. اولین بک‌تست و آموزش (چند دقیقه؛ گزارش خودش باز می‌شود):

```powershell
C:\asli\windows\run_backtest.cmd
```

۵. روشن کردن ربات:

```powershell
Start-ScheduledTask ASLI-Live
```

ربات بعد از هر ریستارت سرور خودش روشن می‌شود و اگر قطع شود بعد از ۳۰ ثانیه دوباره بالا می‌آید. هر یکشنبه ساعت ۳ صبح کد را به‌روز می‌کند، بک‌تست را با داده‌ی جدید تکرار می‌کند و دوباره آموزش می‌بیند.

## اپ موبایل

از بخش **Releases** ریپو فایل `ASLI.apk` را دانلود و نصب کنید. در اولین اجرا آدرس سرور (`http://185.215.244.236:8787`) و توکن را وارد کنید. اپ نشان می‌دهد:

- بالانس، پوزیشن‌های باز و آمار زنده
- هر تصمیم ایجنت مخالف با تمام دلیل‌های موافق و مخالف
- تقویم اقتصادی ۲۴ ساعت آینده
- گزارش کامل بک‌تست
- دکمه‌های توقف، ادامه و بستن همه

## دستورهای مفید

```powershell
cd C:\asli
.venv\Scripts\python run_backtest.py --years 3            # بک‌تست با ۳ سال داده
.venv\Scripts\python run_backtest.py --csv data\csv       # بک‌تست با فایل‌های CSV
.venv\Scripts\python -m pytest -q tests                   # تست‌ها
type logs\asli.log                                         # لاگ ربات
```

بک‌تست تضمین سود آینده نیست. اگر در گزارش، ستون «ASLI ترکیبی» روی داده‌ی تست منفی است، ربات را روی حساب واقعی روشن نکنید؛ روی دمو بماند تا با داده‌ی بیشتر یاد بگیرد.
